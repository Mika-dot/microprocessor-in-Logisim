# MT16 Instruction Set Architecture

MT16 — 16-битная аккумуляторная архитектура. Каждая команда занимает ровно два
байта: `[opcode:8][operand:8]`. Благодаря фиксированной длине каждый поток имеет
собственный 8-битный `PC` и до 128 команд в 256-байтном ROM.

## Регистры и пространства адресов

| Сущность | Размер | Назначение |
|---|---:|---|
| `PC` | 8 бит | адрес следующего байта в ROM текущего потока |
| `ACC` | 16 бит | аккумулятор и левый операнд ALU |
| `IR` | 8 бит | текущий opcode |
| `OPERAND` | 8 бит | непосредственное значение, адрес RAM или перехода |
| `ZERO` | 1 бит | `1`, если последний записанный в `ACC` результат равен нулю |
| ROM T0…T3 | 4 × 256 × 8 | отдельная программа каждого потока |
| shared RAM | 256 × 16 | общая память данных |

Арифметика выполняется по модулю `2^16`. `LDI` расширяет 8-битный операнд нулями.
Адрес перехода — байтовый адрес внутри ROM того же потока. Метки ассемблера
автоматически преобразуются в такие адреса.

## Команды

| Код | Команда | Действие |
|---:|---|---|
| `0x0` | `NOP` | нет операции |
| `0x1` | `LDI imm8` | `ACC ← zero_extend(imm8)` |
| `0x2` | `LD addr` | `ACC ← RAM[addr]` |
| `0x3` | `ST addr` | `RAM[addr] ← ACC` |
| `0x4` | `ADD addr` | `ACC ← ACC + RAM[addr]` |
| `0x5` | `SUB addr` | `ACC ← ACC - RAM[addr]` |
| `0x6` | `AND addr` | `ACC ← ACC AND RAM[addr]` |
| `0x7` | `OR addr` | `ACC ← ACC OR RAM[addr]` |
| `0x8` | `XOR addr` | `ACC ← ACC XOR RAM[addr]` |
| `0x9` | `NOT` | `ACC ← NOT ACC` |
| `0xA` | `SHL` | `ACC ← ACC << 1`, старший бит отбрасывается |
| `0xB` | `SHR` | `ACC ← ACC >> 1`, ноль вдвигается слева |
| `0xC` | `JMP target` | `PC ← target` |
| `0xD` | `JZ target` | если `ZERO = 1`, то `PC ← target` |
| `0xE` | `ATOMADD addr` | атомарно: `old ← RAM[addr]`; `RAM[addr] ← old + ACC`; `ACC ← old` |
| `0xF` | `HALT` | останавливает текущий аппаратный контекст |

`ZERO` обновляют команды, записывающие `ACC`: `LDI`, `LD`, арифметика, логика,
сдвиги и `ATOMADD`. `ST`, переходы и `NOP` флаг не меняют.

## Ассемблер

Файл может содержать четыре секции `.thread 0` … `.thread 3`. Метки локальны
для потока. Общую RAM можно предварительно заполнить директивами:

```asm
.data 0x80 1
.fill 0x90 4 0xffff
```

Минимальный пример межпоточного счётчика:

```asm
.thread 0
    LDI 1
    ATOMADD 0x80
    HALT

.thread 1
    LDI 1
    ATOMADD 0x80
    HALT

.thread 2
    HALT

.thread 3
    HALT
```

Числа принимаются в формате Python (`42`, `0x2a`, `0b101010`) и как одиночные
ASCII-символы (`'A'`). Комментарии начинаются с `#` или `;`.

## Memory-mapped наблюдение

Основная схема выводит записи по адресам `0xF0…0xF3` в шестнадцатеричные порты
`OUT0…OUT3`. Адрес `0x30` дополнительно подключён к монитору `ATOMIC_COUNT`.
Это обычные ячейки RAM: специальное отображение не меняет семантику программы.

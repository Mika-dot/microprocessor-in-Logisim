# Набор команд ЭВМ-7400

Все команды занимают два байта: первый — код операции в младшей тетраде, второй — непосредственное значение или адрес. Такая кодировка упрощает реальный микропрограммный автомат и делает трассу на макете предсказуемой.

| Код | Мнемоника | Операция |
|---:|---|---|
| `0` | `NOP` | Нет операции |
| `1` | `LDI n` | `A ← n` |
| `2` | `LDA a` | `A ← RAM[a]` |
| `3` | `STA a` | `RAM[a] ← A` |
| `4` | `ADD a` | `A ← A + RAM[a]`, обновить `Z/C` |
| `5` | `SUB a` | `A ← A − RAM[a]`, обновить `Z/C` |
| `6` | `AND a` | `A ← A & RAM[a]`, обновить `Z` |
| `7` | `OR a` | `A ← A | RAM[a]`, обновить `Z` |
| `8` | `XOR a` | `A ← A ^ RAM[a]`, обновить `Z` |
| `9` | `JMP a` | `PC ← a` |
| `A` | `JZ a` | Переход, если `Z=1` |
| `B` | `JC a` | Переход, если `C=1` |
| `C` | `OUT` | `OUT ← A` |
| `D–E` | — | Резерв |
| `F` | `HLT` | Останов |

## Микрошаги

- `T0`: чтение кода команды из программного EEPROM, загрузка `IR`, `PC+1`;
- `T1`: чтение операнда, загрузка регистра операнда, `PC+1`;
- `T2`: выполнение простой команды или загрузка второго операнда в `B`;
- `T3`: результат АЛУ в `A`, запись флагов, возврат к `T0`.

`JZ` и `JC` не декодируются отдельной случайной логикой: флаги являются старшими адресными линиями управляющего EEPROM, поэтому условие уже учтено в слове микрокода.

## Умножение и деление

В исходной учебной схеме стояли идеальные блоки `Multiplier` и `Divider`. Для реального макета это десятки дополнительных корпусов и длинный критический путь. В ЭВМ-7400 эти операции выполняются программно:

- умножение — циклом `ADD` с уменьшением счётчика через `SUB 1` и `JZ`;
- деление — повторным `SUB`, записью остатка и увеличением частного; `JC` означает отсутствие заёма.

Так сохраняется вычислительная возможность, но аппаратная часть остаётся собираемой и диагностируемой.

# ЭВМ-7400

`ЭВМ-7400.circ` — самодостаточная версия первой 8-битной ЭВМ, пересобранная на реальных микросхемах серии 74xx из вложенной библиотеки `logi7400`.

## Как запустить

1. Откройте корневой файл `ЭВМ-7400.circ` в Logisim Evolution 4.1.0.
2. Главная схема `ЭВМ_7400` откроется автоматически.
3. Нажмите `RESET`.
4. Включите `Simulate → Ticks Enabled`.
5. Наблюдайте `PC`, `A`, `Step`, `OUT` и красный индикатор `HALT`.

Демонстрационная программа уже записана в `ProgramROM_28C16`. Она выполняет загрузку и запись RAM, сложение с переносом, условный и безусловный переходы, вычитание, `XOR`, `OR`, `AND`, проверку нуля, `OUT` и `HLT`. Ожидаемое конечное значение `OUT` — `0`.

## Что смотреть внутри

- `CPU7400_Core` — вся архитектура и общая шина;
- `ALU8_74xx` — физическая битовая реализация АЛУ;
- `Register8_74xx` — регистр на `74HC74/74HC157`;
- `PC8_74xx` — счётчик команд и параллельная загрузка;
- `ControlStore_28C64` — микрокод;
- `ProgramROM_28C16` и `DataRAM_62256` — реальные внешние микросхемы памяти;
- `FFTest_7474` — отдельная диагностическая схема триггера.

Весь проект встраивает нужные модели `logi7400` внутрь `.circ`, поэтому пользователю не надо вручную подключать библиотеку.

## Проверка

```bash
export LOGISIM_JAR=/path/to/logisim-evolution-4.1.0-all.jar
bash hardware7400/test-all.sh
```

Проверяются АЛУ, все 1024 адреса управляющего ПЗУ, триггер, восьмибитный регистр, счётчик команд и полная потактовая трасса демонстрационной программы.

См. также [ISA](ISA.md) и [ведомость микросхем](BOM.md).
